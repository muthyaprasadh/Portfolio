# Muthya Prasadh — Portfolio

A responsive Dexter-inspired portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Features
- Dark forensic-noir visual system with a light/dark toggle
- Profile, project archive with filters/search, experience, skills and contact sections
- Muthya FC penalty shootout mini-game (client-side demo)
- Fingerprint visitor wall (session-only demo; does not collect biometric data)
- Resume PDF in `public/Muthya_Prasadh_Resume.pdf`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing
- Review and update any project source links that are not yet added.
- Replace the session-only fingerprint wall with a backend if you want marks shared across visitors.
- Add a real GitHub activity integration only if you want live contribution data.
